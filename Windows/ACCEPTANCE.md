# Windows 验收清单

在 Windows 10 22H2 x64 和 Windows 11 24H2 x64 各执行一遍。Windows 11 是主验收环境。

## 安装与生命周期

- `XDecode-Setup-x64.exe`、`XDecode.Windows.exe` 和 Explorer Command 的
  Authenticode 状态均为 `NotSigned`。
- 普通用户无需管理员权限、CER 或 Windows App SDK/.NET 预安装即可完成安装和启动。
- 安装位置为 `%LOCALAPPDATA%\Programs\XDecode`，系统“已安装的应用”中只有一个标准卸载项。
- CI 安装后真实启动应用，主窗口在 30 秒内出现且进程继续存活至少 10 秒。
- 首次启动只出现一个主进程；再次启动、文件关联和右键激活均重定向到该进程。
- 普通启动显示主窗口；开机启动、打开方式和资源管理器右键冷启动不显示窗口。
- 已显示窗口时，再次文件激活不会把窗口隐藏。
- 关闭最后窗口后托盘、监听和可用的系统通知继续工作；托盘“退出 XDecode”终止进程。
- 任务管理器禁用开机启动后，XDecode 不会自动重新启用。

## 文件入口

- 文件选择、拖放和打开方式支持多选 `.xlog`、`.mx`、`.logan`、`.zip`。
- Windows 11 一级右键菜单显示“使用 XDecode 解密”，目录和特殊文件不显示。
- 无扩展名/自定义规则 Logan 可从右键、拖放、选择文件和监控进入主 App 分类。
- `.xlog`、`.mx`、`.logan`、`.zip` 的 OpenWith 注册在卸载后被完整移除。

## 解码与事务

- Xlog 验证 `0x03...0x0D`、加密多私钥顺序、帧损坏、序号缺口、sync-flush 和 zstd。
- Logan 验证 PKCS#7、NoPadding、全零 Key/IV、末帧无分隔符和未结束压缩流。
- MX 验证 FlatBuffers 跳过坏记录、微秒时间戳与 UTF-8/Latin-1。
- 单文件不覆盖已有 `.log`，部分结果不发布，发布后才删除源文件。
- ZIP 永远保留；无日志静默跳过；部分/全部失败目录保留原始日志。
- ZIP 拒绝 Zip Slip、UNC、盘符、ADS、设备名、末尾点/空格、符号链接、大小写重复、
  CRC/实际大小不一致和配额超限。

## 系统能力

- 首次安装默认监听 Downloads，只处理启动后新增文件；显式移除后重启不恢复。
- 新目录补扫描和 `FileSystemWatcher` 缓冲区溢出恢复不会重复处理已有文件。
- ZIP 输出位于监控目录时不会形成自动解密回环。
- 支持 Windows App SDK 通知服务时，通知、最近三条托盘任务、历史 30/200/30 天、
  定位输出和清空历史工作正常；通知服务不可用不得阻止应用启动或解码。
- DPAPI 密钥不出现在设置 JSON、历史、通知、日志或 Explorer 扩展进程中。
- 主动检查更新只访问 `LineShine/XDecode` GitHub Releases，并打开发布页。

## 升级与卸载

- 从旧 MSIX 版本升级时，设置、DPAPI 密钥、监控目录和历史迁移到新的本地数据目录，
  旧 MSIX 随后被移除。
- 使用新版 `setup.exe` 覆盖较低版本时，设置、DPAPI 密钥、监控目录和历史保留。
- 重复运行同版本 `setup.exe` 时显示“卸载后重新安装/直接覆盖”选择；推荐重装方式完成后，
  设置、DPAPI 密钥、监控目录和历史仍然保留。
- `setup.exe` 必须拒绝用旧版本覆盖已安装的新版本。
- 卸载后程序目录、本地应用数据、开机启动、COM 注册、文件关联和托盘入口消失。
- 卸载不删除用户日志、ZIP 和已发布 `.log`/输出目录。
